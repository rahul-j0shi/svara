# Svara Assets

The default VRM avatar, VRMA animations, model metadata, and third-party licence notices will live
here. Git LFS tracks `*.vrm` and `*.vrma`; no production avatar is added until T0.12.

T0.12 selects one exact, licence-verified free VRM (ADR-0007; VRoid presets are **not** CC0) and
commits it with `LICENSES.md` (source, terms as checked, SHA-256, modifications) and its
qualification report.
